# Finlo

Modern Personal Finance Management System

## Tech Stack

- Next.js
- TypeScript
- TailwindCSS
- Prisma
- PostgreSQL

## Main Features

- Income & Expense Tracking
- Wallet Management
- Budget Planning
- Analytics Dashboard
- Financial Reports

## Database

```bash
npm run db:migrate   # migrations
npm run db:seed      # roles & permissions
npm run db:generate  # Prisma client
```

Chi tiết: `docs/03-database/`.
