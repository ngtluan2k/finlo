# Finlo Overview

## Introduction

Finlo is a modern personal finance management platform designed to help users:

- Track income and expenses
- Manage wallets/accounts
- Analyze spending habits
- Create monthly budgets
- Visualize financial reports

## Goals

- Simple UX/UI
- Fast performance
- Scalable architecture
- Mobile responsive
- Modern fintech design

## Target Users

- Students
- Office workers
- Freelancers
- Personal financial planners
